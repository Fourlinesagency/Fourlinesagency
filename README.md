# Fourlines Agency

We're a web agency ([fourlinesagency.com](https://fourlinesagency.com)). We also make
**[PrepMyPost](https://prepmypost.com)**: free tools for creators and small businesses that run in your browser, so your
photos, videos and documents aren't uploaded.

## Open source

| Repo | What it does | Live tool |
|---|---|---|
| [video-metadata-cleaner](https://github.com/Fourlinesagency/video-metadata-cleaner) | Remove GPS, device and dates from MP4/MOV in place, no re-encoding | [Remove metadata from video](https://prepmypost.com/remove-metadata-from-video) |
| [image-dpi](https://github.com/Fourlinesagency/image-dpi) | Change JPEG/PNG DPI without touching the pixels | [Change DPI of image](https://prepmypost.com/change-dpi-of-image) |
| [social-media-sizes](https://github.com/Fourlinesagency/social-media-sizes) | Image sizes, text limits and safe zones as data, with sources | [Social media image sizes](https://prepmypost.com/social-media-image-sizes) |
| [video-prompt-terms](https://github.com/Fourlinesagency/video-prompt-terms) | The viral /droneshot-style "commands" (166) mapped to the words AI video tools read, plus a prompt builder | [AI video prompt commands](https://prepmypost.com/ai-video-prompt-commands) |

All MIT, no dependencies.
